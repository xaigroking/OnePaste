## Try it in 3 steps
Use the portable desktop downloads for Windows and macOS. No source build or development tools are needed.

1. **Start the server** on a computer that stays on and is reachable by both desktops. For Docker, follow **Run the server with Docker** below from start to finish; it does not require a `tools` download. Alternatively, unzip the `tools` package on the server and run `.\onepaste-server.exe` on Windows or `./onepaste-server` on macOS/Linux. Copy the complete `onepaste1:` connection code it prints. For cross-network access, configure `ONEPASTE_PUBLIC_URL` with the server's reachable HTTPS address.
2. **Open the first desktop.** Unzip the desktop download, follow **First launch**, choose **Connect to my own server**, paste the code and click **Next**. For an empty vault, choose and confirm a passphrase, save the recovery kit offline, check the saved confirmation and click **Done**. For an existing vault, use its original passphrase to **Join**, or use the recovery-kit entry if you forgot it.
3. **Add the second desktop.** On the connected desktop, open **Devices → Add a device → Make a connection code** and copy the new code. On the second desktop, choose **Connect to my own server**, paste the new code and join with the same passphrase. If the connected desktop is unavailable, run the server program with `connect-code` to obtain a fresh code. Codes are single-use and a newly generated code replaces unused older codes. Keep them private. Copy distinctive text A → B and then different text B → A; confirm each appears in the receiving history and can be copied. Server startup alone does not confirm sync.

The server programs on macOS are also unsigned; `READ-ME-FIRST.txt` in the tools package explains how to allow them.
